# Itsucara Homebrew Tap

Homebrew casks for software published by [Itsucara](https://itsucara.com).

## Install

```sh
brew install --cask itsucara/tap/kagisecure
```

Or tap once and use the short name:

```sh
brew tap itsucara/tap
brew install --cask kagisecure
```

## Casks

| Cask | Description |
| --- | --- |
| [`kagisecure`](Casks/kagisecure.rb) | Local-first password manager for macOS that lets AI agents use secrets without seeing them. [Source](https://github.com/itsucara/kagisecure) |

Every app distributed here is signed with a Developer ID certificate and notarized by Apple.

## Reporting problems

Issues with an app itself belong in that app's repository. Issues with a cask definition —
a wrong checksum, a broken URL — can be filed here.
